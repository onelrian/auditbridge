# Support

Use GitHub Discussions for installation and usage questions. Use GitHub Issues
for reproducible defects and feature requests.

Before opening an issue, include the AuditBridge version or image digest, sink
configuration with credentials removed, relevant logs, and the exact command or
deployment method used. Do not post access tokens, authorization headers, or
customer audit events.

Security reports belong in the private process described in [SECURITY.md](SECURITY.md).
